# Flights to Bogotá

Brisbane to Bogotá and back without transiting the USA: sampled economy return fares
by departure and return date for each routing, each marked with the day it was priced,
with a Google Flights link for any pair of dates.

Single page, no build step: open `index.html`. The CSV files are the fare samples the
page was built from.

Fares were read from Google Flights on 11 September and 13 October 2026 and move daily.
Transit and visa notes are general information as at those dates: check the official
source before booking.
